# 📺 HiTV - Android IPTV 播放器

Tivimate、PerfectPlayer都是非常好的播放器，但是设置太多，配置麻烦。还需要收费，我就需要个能放IPTV的软件就行，于是用AI做了这个，适合中国人的操作方式，方便的手机推送配置,没有多余的设置，看AI怎么吹。

## 技术栈架构 (Tech Stack)

| **维度**       | **选型**                           | **说明**                                            |
| -------------- | ---------------------------------- | --------------------------------------------------- |
| **UI 框架**    | **Compose for TV (M3 1.0.1)**      | 利用声明式 UI 快速实现 Apple TV 级动效。            |
| **播放引擎**   | **Media3 1.9.0 (ExoPlayer) + MPV** | 双引擎方案，Media3 为主，MPV 作为高性能硬骨头回退。 |
| **解码增强**   | **FFmpeg Extension**               | 解决非标直播流和特定音频格式的解码问题。            |
| **异步/网络**  | **Coroutines + Retrofit 3.0**      | 配合 OkHttp 4.12 处理高并发请求与流式解析。         |
| **数据持久化** | **Room 2.8.4 + DataStore**         | Room 存储频道/EPG，DataStore 存储轻量配置。         |
| **依赖注入**   | **Hilt 2.57.2**                    | 解耦模块，方便单元测试与组件替换。                  |
| **图片加载**   | **Coil 3.3.0**                     | 针对 Compose 优化的图片加载，支持多级缓存。         |

**HiTV** 是一款专为 Android TV / 机顶盒 打造的开源 IPTV 播放器。采用前沿的 `Jetpack Compose for TV` 构建，内置 **Media3 (ExoPlayer)** 与 **Native MPV** 双引擎。

本项目致力于解决国内各种“野生 IPTV 源”和“老旧机顶盒（如 Amlogic/Rockchip）”带来的各种疑难杂症：**彻底告别黑屏、解码器死锁、起播慢、EPG 时间错乱等问题。**

## ✨ 核心特性

### 🚀 强悍的“双擎”播放架构

- **主战引擎 (Media3 / ExoPlayer)**：
  - **三级智能降级装甲**：策略0(智能嗅探) -> 策略1(强制 HLS 无切片探测) -> 策略2(强解 MP2T 脏流)。
  - **神级防卡顿控制**：1.5 秒极速起播，2 秒网络微抖动抗性，彻底抹平走走停停的闪烁感。
- **核武兜底引擎 (C++ MPV)**：
  - 专治各种 ExoPlayer 无法解析的“脏流”和“烂源”。
  - 针对 Amlogic 等低端芯片深度调优：强制 `mediacodec_embed` 渲染与 `auto` 硬解，仅保留 `1M` 极限缓存。完美规避音视频时钟同步导致的**硬件解码器死锁**问题，点开即秒播。

### 📡 极速、精准的 EPG (电子节目单) 系统

- **双轨穿透匹配**：完美兼容标准 XMLTV 格式与各种魔改格式。优先使用 `tvg-id` 匹配，失败时自动无缝降级为 `channelName` 模糊匹配。
- **NTP 强制校时**：内置阿里云 NTP (`ntp.aliyun.com`) 强同步。即使电视盒子的纽扣电池没电、本地时间回到 1970 年，EPG 时间轴依然绝对精准！
- **防 OOM 流式解析**：基于 `XmlPullParser` 与 `Kotlin Flow` 的流式解析，1000 条/批次滚动入库，面对几万个频道的庞大 XML 文件也能在低端盒子上如丝般顺滑。

### 🎮 为大屏而生的交互体验

- **纯 Compose 打造**：抛弃传统 Android View，UI 完全基于 `Jetpack Compose` 构建，流畅度极佳。
- **完美的按键映射**：
  - `上/下` 键：快速换台。
  - `左/右` 键：呼出底部 EPG 节目信息卡片。
  - `数字键`：支持防抖延迟换台或按确认键秒切。
  - `长按确认键`：呼出右侧高级设置与 Debug 探针面板。
- **原生生命周期感知**：切入后台 (Home 键) 瞬间释放底层解码器防漏音，切回前台瞬间无缝接管恢复播放。

### 📱 局域网扫码隔空传源

- 丢掉难用的遥控器输入法！电视端内置 `NanoHTTPD` 微型 Web 服务器，只需用手机扫描电视上的二维码，即可在手机浏览器中一键推送 M3U 和 EPG 链接。

## 🛠️ 技术栈

- **UI 层**: Jetpack Compose (TV Design)
- **架构**: MVVM + Hilt (依赖注入)
- **异步与响应式**: Kotlin Coroutines + Flow
- **本地存储**: Room Database + DataStore
- **网络请求**: OkHttp3
- **播放内核**: AndroidX Media3 (ExoPlayer) + `dev.jdtech.mpv:mpv-android`
- **其他**: Zxing (二维码生成)

## 🚀 编译与运行

1. 克隆本项目：

   Bash

   ```
   git clone https://github.com/你的用户名/HiTV.git
   ```

2. 使用 **Android Studio (推荐最新版)** 打开项目。

3. 等待 Gradle 同步完成后，直接运行到 Android TV 模拟器或通过 ADB 连接的实体机顶盒上。

## 💡 使用指南

1. **初次启动**：App 会显示一个二维码和局域网 IP 地址。
2. **手机扫码**：确保手机和电视在同一局域网下，扫码打开控制台。
3. **推送地址**：在手机网页上输入您的 M3U 订阅源和 EPG XML 链接，点击“推送”。
4. **自动拉取**：电视端收到指令后，会自动下载、解析并存入本地数据库，随后自动开始播放。
5. **呼出菜单**：在播放界面，长按遥控器 `确认/OK` 键可呼出高级菜单，您可以随时切换底层内核或查看 Debug 探针信息。

## 📝 核心排错 (Debug 面板)

如果你遇到某个频道黑屏或没有 EPG，长按 OK 键打开“显示底层 Debug 探针面板”：

- **解码器卡死**：观察 MPV 的 `硬件解码状态` 是否正常输出，或 ExoPlayer 的丢帧数是否狂飙。
- **EPG 不显示**：面板会精准输出当前频道的 `tvgId` 和 `channelName`，以及数据库命中数量。对比你的 XML 文件，一秒就能揪出名称不匹配或时间过期的脏数据。
